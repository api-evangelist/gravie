## Notes for agents

- There is no public Gravie API, SDK, CLI, sandbox, changelog, status page or OpenAPI/AsyncAPI/GraphQL/MCP
  surface. api.gravie.com is an authenticated gateway backing the Gravie mobile and member apps; it returns
  HTTP 403 `{"message":"Forbidden"}` for every anonymous path, including /.well-known/*.
- The portal hosts member.gravie.com and employer.gravie.com are single-page applications whose catch-all
  route returns HTTP 200 with the app HTML shell for any path. Do not treat a 200 from those hosts as evidence
  that a document exists.
- Provider-side integration is EDI, not HTTP: X12 837 claims under payer IDs GRV01 and 62308, submitted
  through the Smart Data Stream clearinghouse for Aetna Signature Administrators plans.
